# Reproducibility controls and upstream model sources

## What is kept in this repository

* `src/rf_quality/models/inception_local.py` is **our own, local, PyTorch
  InceptionTime-style network**. It is a *single* six-block residual CNN and
  **not the original five-model ensemble** reported in the InceptionTime paper.
* `src/rf_quality/models/adapters.py` contains our own convolutional autoencoder,
  training wrappers and classifier interfaces.
* XGBoost, Isolation Forest, MultiROCKET and the PyTorch tensor runtime continue
  to come from third-party packages. XGBoost and PyTorch contain substantial
  native/compiled code; simply copying a few Python files into this repository
  would not make them independent of those libraries.
* `third_party/sources.json` fixes audited upstream Git commit SHA values for
  reference/reproduction. `scripts/fetch_upstream_sources.sh [name...]` checks
  out the **exact commits**, rather than today's default branches. These are
  source reference checkouts; runtime still uses installed Python distributions.

## Mandatory release procedure (network-enabled Linux/WSL)

1. Install Python 3.12 and `uv`, then run `bash scripts/generate_lock.sh`.
2. **Commit `uv.lock`** alongside `pyproject.toml`. Use `uv sync --locked
   --extra all --extra dev` on fully provisioned machines; the script first
   installs a lighter, locally testable stack without Digital RF/aeon.
3. Record `python --version`, `uv --version`, OS/CPU/GPU, package versions,
   training dataset SHA-256, the split JSON, seeds, grid file, trained bundle
   manifest and final report in your scientific submission.
4. Run `pytest -q`, `rf-quality synthetic`, and the real PSWS end-to-end tests.
5. Use a fresh clean environment to reproduce training and inference. Test
   both native InceptionTime and aeon MultiROCKET with the **locked versions**.

**Current artifact limitation:** `uv.lock` cannot be generated in the offline
build environment because third-party dependency metadata is not cached. It
must be resolved and committed on your network-enabled development machine.
Until then, `>=` requirements in `pyproject.toml` are NOT exact reproducibility.
Upstream Git SHAs do not pin PyPI transitive dependencies by themselves.

## Backward compatibility

InceptionTime model bundles generated by the earlier 0.1.0 project use the
`tsai` implementation. When a legacy artifact lacks an explicit `backend`,
loading it selects the legacy `tsai` architecture. New bundles record the
`native` architecture. Keep exact compatible tsai versions if old bundles must
be loaded; use `.[legacy-tsai]` only for those. Model-bundle checksums do not
make untrusted joblib safe to open.

## Licensing

Do not copy XGBoost, PyTorch, scikit-learn, aeon, or tsai into the repository
without carrying forward the applicable original licenses, notices and any
required attribution. Keeping isolated upstream source checkouts makes that
process auditable; do not redistribute the GPL-licensed HamSCI reference code
inside this project without reviewing the license obligations.
